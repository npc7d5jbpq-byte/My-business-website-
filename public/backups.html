How automatic backups work

Every change you make is saved to disk immediately, so nothing is ever held only in memory — closing the app, restarting the computer, or a power cut does not lose data. On top of that, this system automatically takes a separate timestamped backup copy: once whenever the app starts, every 15 minutes while it's running if anything changed, and once more when the app is closed.

Backups are kept on a rolling schedule so the folder never grows without bound: every backup from the last 48 hours, one per day for the last 30 days, and one per month after that, forever.

Secondary backup location (USB drive / network folder)

Automatic backups above still live on this same computer. Point this at a USB drive or a network folder and every backup will also be copied there automatically — a real off-machine safety copy, kept in sync without anyone needing to remember. If the drive isn't plugged in when a backup runs, it's simply copied over the next time it's connected.

On the desktop app, File → Set Secondary Backup Location opens a folder picker instead of typing a path.
